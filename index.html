일단 푸시

일단 푸시는 여섯 명의 팀원이 HTML, CSS, JavaScript를 바탕으로 하나의 웹사이트를 공동 개발하며, Git과 GitHub 기반 협업 프로세스를 경험하는 팀 프로젝트 단위이다.

웹 페이지를 간략하게 소개하는 포트폴리오 사이트를 구축하는 동시에 브랜치 관리, Pull Request, 코드 리뷰, 일정 조율, 배포 및 발표 전 과정을 수행한다.

1. 개요

일단 푸시는 6인 공동 웹 개발을 통해 협업 역량을 기르기 위해 만든 프로젝트 팀이다. 기본 화면 구조와 소개 섹션을 중심으로 구성되며, 별도 하위 페이지로 확장할 수 있도록 설계했다.

2. 팀 구성 및 역할

2.1. 역할 분담표

순번 이름 담당 역할
1 이윤진 메인 페이지(Main Page) UI 구현 및 전체 레이아웃 설계
2 박현정 전체 서비스 UI/UX 디자인 및 스타일 가이드 수립
3 김서영 개발 과정(Development Process) 페이지 개발 및 협업 히스토리 정리
4 이병민 갤러리(Gallery) 페이지 개발 및 미디어 아카이빙 뷰 구현
5 정희돈 팀 소개(About Team) 페이지 개발 및 프로젝트 비전 시각화
6 박지훈 팀원 소개(Team Members) 페이지 개발 및 프로필 인터랙션 구현

3.1. 개발 목표

본 프로젝트는 팀원 6명이 HTML, CSS, JavaScript를 활용해 하나의 웹사이트를 완성하는 과정에서 Git과 GitHub를 활용한 협업 역량을 강화하는 것을 목적으로 한다.
